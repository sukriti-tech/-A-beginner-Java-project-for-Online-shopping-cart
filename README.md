**Abstract:**

The Online Store Cart & Order Pipeline is a Java-based project that develops the basic process of purchasing products through an online store. The main purpose of the project is to create a simple and organized system in which a user can view available products, select items, add them to a shopping cart, modify quantities, remove items, get feedback, and check the total cost before placing an order. The main idea is to track the journey of a product from the moment a customer selects it, through the shopping cart and order placement, until the order is delivered.

The system includes product details such as product name, product ID, price, available quantity, applicable discounts, coupons, deals, payment options, and other additional features. After the customer confirms the cart, an order is created and moves through the stages of Order Placed, Order Confirmed, Packed, Shipped, and Delivered.

The project focuses on representing a real-world online shopping workflow using core Java programming concepts rather than building a complete commercial application.
